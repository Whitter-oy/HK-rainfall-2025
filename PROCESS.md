# Process

I used ChatGPT during this assignment mainly as a programming and debugging assistant. I am still new to Python, so I used it to help me understand error messages, inspect the structure of the Hong Kong Observatory CSV file, and develop the visualisation step by step.

I started with a very simple line chart of daily rainfall. After confirming that the CSV values were being read correctly, I experimented with a circular rainfall wheel. The wheel was visually more interesting, but I felt that it was still too static and did not allow the viewer to explore the data clearly.

One AI-assisted idea that I kept was the use of an interactive month and day selector. I liked this because it made the 365 daily rainfall records easier to explore. I also kept the suggestion of linking the animated rain effect to the actual daily rainfall value. This made the animation meaningful rather than purely decorative.

One idea I rejected was representing different Hong Kong districts with different rainfall intensities. My dataset only contains rainfall measured at the Hong Kong Observatory station, so colouring districts differently would imply that I had district-level rainfall data when I did not. Instead, I kept the district boundaries only as geographic context and clearly stated this limitation in the interface.

I also used ChatGPT to help debug Python syntax errors, improve the layout, and organise the HTML, CSS and JavaScript generated by `plot.py`. I tested each change locally and adjusted the design based on what I could see in the browser.
